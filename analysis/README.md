# Analysis Scripts

This directory contains code used to produce thesis diagnostics and figures.

Only scripts are included. The CSV source tables, generated images, runtime logs, and benchmark outputs are intentionally omitted from this code release.

- `measure_runtime_sanity.py`: runtime/FPS and memory sanity check helper.
- `generate_chapter4_visuals.py`: plotting script for Chapter 4 visualizations, assuming the omitted source CSV files are regenerated or supplied separately.
